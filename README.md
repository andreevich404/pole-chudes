# Поле тайн

Интерактивная игра со словами и барабаном **по мотивам классической механики** телеигры. Играете вы и два бота: три тура, затем суперигра для лидера. Весь интерфейс на русском.

> Воспроизведена только механика и правила. Графика, ведущий (Аркадий Блеск), персонажи, логотип, название, фразы и звуки — оригинальные, нарисованные и написанные специально для этого проекта. Вопросы и слова тоже авторские.

## Правила

1. Играют трое: вы («Игрок» или своё имя), «Робот Вольт» и «Бабушка Клава». Ходят по очереди; в каждом туре первым ходит следующий игрок по кругу.
2. В туре задан вопрос-подсказка и загадано слово или фраза (4–11 букв). Слово выложено на табло закрытыми ячейками.
3. Свой ход начинается с вращения барабана: кнопкой «Крутить барабан» или жестом — потяните барабан мышью или пальцем и отпустите. Результат определяется физически: сектор под указателем по итоговому углу.
4. Если выпали очки, называете **букву** (экранная или физическая клавиатура; раскладка QWERTY тоже работает) или **слово целиком** (доступно после первой открытой буквы).
5. Верная буква открывается во всех ячейках, вы получаете очки сектора × число вхождений и крутите снова. Ошибка — ход переходит.
6. Верное слово выигрывает тур: очки тура победителя переходят в общий счёт, у остальных сгорают. Если слово открыто по буквам полностью, тур выигрывает тот, кто открыл последнюю.
7. Неверное слово целиком — ход переходит.
8. «Звонок другу» — один раз за игру открывает случайную букву без очков.
9. После трёх туров лидер выходит в **суперигру**: назвать 3 буквы, затем ещё 3 новых, затем одна попытка на слово. Если лидер — бот, суперигра пропускается и показывается итог.

### Секторы барабана (21 сектор)

| Сектор | Что делает |
| --- | --- |
| 100, 150, 200, 250, 300, 350, 400, 500, 600, 700, 800, 900, 1000 | Очки за каждую открытую букву |
| Банкрот (×2) | Теряете очки тура, ход переходит |
| Ноль | Ход переходит |
| Плюс | Откройте любую букву на табло (очки не начисляются) |
| Приз (300 за букву) | После верной буквы: «Взять приз» (ход переходит) или «Продолжить игру» (приз получите за победу в туре) |
| Ключ (100 за букву) | +500 очков сразу и шкатулка со случайным призом в итоговом экране |
| ×2 | Удвоение: 250 × 2 = 500 за каждую букву |
| Удача (200 за букву) | Случайный бонус 100–1000 очков сразу |

Рекорд = итоговый счёт игрока (+3000 за победу в суперигре). Рекорд и имя хранятся в `localStorage`.

## Стек

- Vite 8, Vue 3 (`<script setup>`, TypeScript strict, без `any`)
- Tailwind CSS 4 (`@tailwindcss/vite`)
- motion-v (Vue-порт Framer Motion) — анимации интерфейса и расчёт вращения барабана
- three.js — 3D-барабан, фон студии и салют (подключается точечно и лениво)
- @vueuse/core — медиазапросы, `prefers-reduced-motion`, события
- Vitest — юнит-тесты чистой логики
- Шрифты Google Fonts с кириллицей: Russo One (заголовки и барабан), Rubik (табло), Onest (текст)

## three.js

Все три слоя подгружаются динамическим `import()` отдельным чанком, импорты точечные (`import { WebGLRenderer, … } from 'three'`).

- **3D-барабан** (`three/wheelScene.ts`). Круглый барабан с лицом из `CanvasTexture` (секторы и подписи на кириллице рисуются на canvas шрифтом Russo One), золотой обод (`MeshStandardMaterial`, металл + карта окружения `RoomEnvironment`), шпильки по ободу, указатель сверху, ambient + две точечных + прожектор с мягкой тенью, лёгкий наклон к камере, покачивание камеры от мыши и гироскопа.
  Угол считает логика (motion-v `animate` + drag-раскрутка), он передаётся в сцену; сектор под указателем определяет `sectorIndexAtAngle` из `engine.ts` (покрыта тестами). Щелчок указателя при прохождении шпилек сохранён.
- **Фон студии** (`three/studioScene.ts`): отдельный canvas с `pointer-events: none` за всем интерфейсом — прожекторные лучи (шейдер, аддитивное смешивание) и парящие золотые искры (`Points`), лёгкий параллакс.
- **Эффекты** (`three/fxScene.ts`, `FxLayer`): при победе в туре, суперигре и финале — салют (`Points`) и конфетти (`InstancedMesh`) поверх интерфейса; при «Банкроте» — красная вспышка и тряска камеры барабана и фона. Слой создаётся только при первом эффекте и рендерит лишь пока эффект идёт.
- **Надёжность и производительность:** `pixelRatio` не выше 2; `setAnimationLoop` останавливается при скрытой вкладке (`visibilitychange`); ресайз через `ResizeObserver`; при размонтировании освобождаются геометрии, материалы, текстуры и рендерер (`dispose`, `forceContextLoss`). Если WebGL недоступен или создание рендерера падает, игра остаётся играбельной: показываются прежний SVG/CSS-барабан и 2D-конфетти. При `prefers-reduced-motion` отключены покачивание камеры, тряска, частицы фона, салют и вспышка; барабан вращается как обычно.

## Список анимаций

motion-v:
- `animate()` + `useMotionValue` — вращение барабана (cubic-bezier ease-out, плавное замедление) и drag-раскрутка с расчётом скорости отпускания; «щелчок» указателя;
- `<Motion>` с `rotateY` — переворот ячеек табло по очереди; заставка названия с последовательным открытием букв;
- `<AnimatePresence mode="wait">` — смена экранов; всплывающие очки («+300», «Приз!»), «Банкрот!» с тряской по `x`;
- spring-масштабирование активной карточки игрока, появление призов на витрине, полосы счёта между турами;
- `whileHover` / `whilePress` на крупных кнопках; появление баннера победы в туре.

CSS: бегущие лампочки по периметру табло и барабана, пульсация активного игрока и кликабельных ячеек («Плюс»), моргание и жесты ведущего (руки меняют положение по настроению: радость, удивление, огорчение, раздумье).

three.js: вращение 3D-барабана, покачивание указателя и камеры, прожекторные лучи, парящие частицы, салют и конфетти, тряска камеры.

Звук (Web Audio, осциллятор): щелчок, верная буква, ошибка, банкрот, фанфары. По умолчанию выключен, переключатель в углу экрана.

## Деплой на GitHub Pages

В `vite.config.ts` задано `base: './'`, поэтому сборка работает из любого подкаталога. Workflow `.github/workflows/deploy.yml` запускается при push в `main` или вручную: ставит зависимости, прогоняет `npm test`, собирает проект и публикует `dist/` через `deploy-pages`. В настройках репозитория выберите Pages → Source: GitHub Actions.
