# Поле чудес · 3D Edition

Интерактивная игра со словами и барабаном **по мотивам классической механики** телеигры. Играете вы и два бота: три тура, затем суперигра для лидера. Весь интерфейс на русском.

## Правила

1. Играют трое: вы («Игрок» или своё имя), «Робот Вольт» и «Бабушка Клава». Ходят по очереди; в каждом туре первым ходит следующий игрок по кругу.
2. В туре задан вопрос-подсказка и загадано слово или фраза (4–11 букв). Слово выложено на табло закрытыми ячейками.
3. Свой ход начинается с вращения барабана: кнопкой «Крутить барабан» или нажатием на барабан в 3D-студии. Результат определяется физически: сектор под указателем по итоговому углу.
4. Если выпали очки, называете **букву** (экранная или физическая клавиатура; раскладка QWERTY тоже работает) или **слово целиком** (доступно после первой открытой буквы).
5. Верная буква открывается во всех ячейках, вы получаете очки сектора × число вхождений и крутите снова. Ошибка — ход переходит.
6. Верное слово выигрывает тур: очки тура победителя переходят в общий счёт, у остальных сгорают. Если слово открыто по буквам полностью, тур выигрывает тот, кто открыл последнюю.
7. Неверное слово целиком — ход переходит.
8. «Звонок другу» — один раз за игру открывает случайную букву без очков.
9. После трёх туров лидер выходит в **суперигру**: назвать 3 буквы, затем ещё 3 новых, затем одна попытка на слово. Если лидер — бот, суперигра пропускается и показывается итог.

### Секторы барабана (21 сектор)

| Сектор | Что делает |
| --- | --- |
| 100, 150, 200, 250, 300, 350, 400, 500, 600, 700, 800, 900, 1000 | Очки за каждую открытую букву |
| Банкрот (×2) | Теряете очки тура, ход переходит |
| Ноль | Ход переходит |
| Плюс | Откройте любую букву на табло (очки не начисляются) |
| Приз (300 за букву) | После верной буквы: «Взять приз» (ход переходит) или «Продолжить игру» (приз получите за победу в туре) |
| Ключ (100 за букву) | +500 очков сразу и шкатулка со случайным призом в итоговом экране |
| ×2 | Удвоение: 250 × 2 = 500 за каждую букву |
| Удача (200 за букву) | Случайный бонус 100–1000 очков сразу |

Рекорд = итоговый счёт игрока (+3000 за победу в суперигре). Рекорд и имя хранятся в `localStorage`.

## Стек

- Vite 8, Vue 3 (`<script setup>`, TypeScript strict, без `any`)
- Tailwind CSS 4 (`@tailwindcss/vite`)
- motion-v (Vue-порт Framer Motion) — анимации интерфейса и расчёт вращения барабана
- three.js — 3D-барабан, фон студии и салют (подключается точечно и лениво)
- @vueuse/core — медиазапросы, `prefers-reduced-motion`, события
- Vitest — юнит-тесты чистой логики
- Шрифты Google Fonts с кириллицей: Russo One (заголовки и барабан), Rubik (табло), Onest (текст)

## Запуск

```bash
npm ci
npm run dev      # режим разработки; в dev доступен window.__game для отладки
npm test         # юнит-тесты engine и бота
npm run build    # проверка типов + сборка в dist/
npm run preview
```

## Структура

```
src/
  game/        engine.ts (чистая логика), bot.ts, questions.ts (80+ вопросов),
               wheelSectors.ts, prizes.ts, phrases.ts, *.test.ts
  composables/ useGame (конечный автомат на реактивном состоянии), useBot, useSound, useStorage
  components/  StartScreen, GameScreen, Wheel, WheelPointer, Tablo, TabloCell, Keyboard,
               PlayersPanel, PlayerCard, Host, RoundIntro, SuperGame, ResultScreen,
               Confetti, PrizeShelf, SoundToggle, StudioBackground, FxLayer
  three/       wheelScene, studioScene, fxScene, wheelTexture, parallax, effects, support
  types/       общие типы
```

Фазы игры (`Phase`): `start → roundIntro → awaitSpin → spinning → chooseLetter | plusPick → revealing → … → roundEnd → (roundIntro | superIntro → superPick → superWord → superResult) → gameOver`.

## Студия Three.js

Игра проходит в единой объёмной студии (`src/three/studioScene.ts`), которая подгружается динамически. Барабан, табло, подиум, стойки игроков, зрительские кресла, световые арки и прожекторы находятся в общем пространстве.

- Барабан стоит горизонтально на металлическом основании. На диске — 21 сектор, шпильки и неподвижный указатель. CanvasTexture рисует кириллицу без внешних изображений. Вращение с замедлением передаёт результат в существующую логику через `wheelBridge`; `targetAngleForSector` и `sectorIndexAtAngle` сохраняют соответствие сектора и указателя.
- Табло состоит из отдельных объёмных ячеек: при верной букве они поворачиваются. «Плюс» поддерживает выбор через Raycaster и доступное экранное табло.
- Чёткость: рендеринг с учётом Retina (до 3×), supersampling на обычных экранах, текстура барабана до 4096 px и анизотропная фильтрация надписей.
- Автокамера следует фазам игры: барабан при подготовке и вращении, табло при выборе и открытии букв, общий план при передаче хода и выборе приза. Ручной ракурс сохраняется до нажатия «Авто». Контрастный указатель и индикатор текущего сектора помогают следить за результатом.
- Камеры: общий план, крупный план барабана и табло. Переходы плавные; расстояние камеры адаптируется к узкому экрану.
- Материалы используют металлические отражения и окружение RoomEnvironment, освещение — прожекторы, точечные источники и тени. Пол отражает студию через Reflector в повышенном разрешении. Декорации имеют скруглённые грани.
- Интерфейс поверх студии: вопрос, счёт, реплики ведущего, клавиатура и игровые действия. Нажатие на сам 3D-барабан также запускает вращение.
- Если WebGL недоступен, доступны запасной SVG-барабан и обычное табло. Предпочтение reduced motion отключает движение камеры и ускоряет вращение. Рендеринг приостанавливается в скрытой вкладке; ресурсы освобождаются при размонтировании.

`StudioBackground.vue` связывает сцену с состоянием игры, `cameraDirector.ts` выбирает автоматический ракурс, а `studioBridge.ts` хранит режим камеры и статус сцены. `StudioViewport.vue` размещает существующий WebGL-canvas в отдельной ячейке сетки через Teleport: вопрос, счёт и панель действий не перекрывают сцену. При прокрутке и изменении размера экрана canvas движется вместе со своей областью, сохраняя WebGL-контекст. Старый `wheelScene.ts` используется только запасным компонентом Wheel. Эффекты победы и банкротства остаются в `FxLayer`.

Звук (Web Audio): щелчки, верная буква, ошибка, банкрот и фанфары. По умолчанию выключен; переключатель находится в шапке.

## Деплой на GitHub Pages

В `vite.config.ts` задано `base: './'`, поэтому сборка работает из любого подкаталога. Workflow `.github/workflows/deploy.yml` запускается при push в `main` или вручную: ставит зависимости, прогоняет `npm test`, собирает проект и публикует `dist/` через `deploy-pages`. В настройках репозитория выберите Pages → Source: GitHub Actions.

## Проверка 3D-интерфейса

`npm test` проверяет игровую логику, ботов и выбор ракурсов камеры; `npm run build` проверяет типы и собирает production-версию.

При проверке в браузере пройдены 35 комбинаций размеров экрана и фаз игры: ширина 320–1920 px, портретная и альбомная ориентация, длинный вопрос, длинное имя, большой счёт, клавиатура, ввод слова, «Плюс» и выбор приза. Проверены отсутствие горизонтального переполнения и пересечений сцены с вопросом, счётом и управлением. Дополнительно пройден тур с автоматической камерой, ручным ракурсом и возвратом в «Авто».
